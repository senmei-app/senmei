# Code Simplification & Optimization Plan

## Priorität 1: Error-Mapping Helper (HIGH — ~50 Call-Sites)

**Problem:** `.map_err(|e| Error::new(e.to_string()))?` wiederholt sich ~50× in `load.rs`, `pth.rs`, `safetensors.rs`, `onnx.rs`.

**Fix:** Helper in `crates/senmei-ml/src/lib.rs`:
```rust
pub(crate) fn map_err<T>(r: Result<T, impl std::fmt::Display>) -> Result<T> {
    r.map_err(|e| Error::new(e.to_string()))
}
```
Dann überall `map_err(m.load_from(store))?` statt `.map_err(|e| Error::new(e.to_string()))?`.

**Dateien:** `engine/load.rs`, `convert/pth.rs`, `convert/safetensors.rs`, `convert/onnx.rs`

---

## Priorität 2: `apply_and_save` Shared Helper (HIGH)

**Problem:** `pth.rs` und `safetensors.rs` wiederholen `m.load_from(&mut store).map_err(...)?; m.save_into(&mut save).map_err(...)?;` — `onnx.rs` hat bereits `apply_and_save` aber es wird nicht geteilt.

**Fix:** `apply_and_save` nach `convert/mod.rs` verschieben, in allen drei Submodulen nutzen.

**Dateien:** `convert/mod.rs`, `convert/pth.rs`, `convert/safetensors.rs`, `convert/onnx.rs`

---

## Priorität 3: RGB8 Input Validation Dedup (MEDIUM)

**Problem:** `infer_rgb8_batch_prepare` und `infer_rgb8_full_frame_batch_prepare` haben identische 18-Zeilen Validierungsblöcke.

**Fix:** Helper extrahieren:
```rust
fn validate_batch_inputs(inputs: &[Tensor]) -> Result<(usize, usize, usize, usize)>
```

**Datei:** `engine/rgb8.rs`

---

## Priorität 4: `mcp.rs` Repeated Error Strings (MEDIUM)

**Problem:** 6× `"render not compiled in (build with --features render)".to_string()` in `mcp.rs`.

**Fix:** Konstante `const RENDER_UNAVAILABLE: &str = "render not compiled in (build with --features render,http)";` und `.into()` nutzen.

**Datei:** `crates/senmei-server/src/mcp.rs`

---

## Priorität 5: `encoder/select.rs` Duplicated Bitrate (LOW)

**Problem:** `format!("{}k", width as u64 * height as u64 / 144)` in `pick_from_caps` und `override_codec_args`.

**Fix:** Helper `fn bitrate_kbps(width: u32, height: u32) -> String`.

**Datei:** `crates/senmei-media/src/encoder/select.rs`

---

## Priorität 6: `.to_string()` → `.into()` Konsistenz (LOW)

**Problem:** ~25 `.to_string()` auf String-Literaten in `encoder/mod.rs`, `encoder/tests.rs`, `decoder.rs`, `lifecycle.rs`.

**Fix:** Systematisch `.into()` ersetzen wo `String` erwartet wird.

**Dateien:** `encoder/mod.rs`, `encoder/tests.rs`, `decoder.rs`, `render/lifecycle.rs`

---

## Priorität 7: `Encoder::open` Sentinel-Parsing extrahieren (MEDIUM)

**Problem:** `Encoder::open` (140 Zeilen) hat 4+ Verschachtelungsebenen beim Sentinel-Parsing (`-senmei_encoder`, `-senmei_vaapi`).

**Fix:** `fn parse_sentinels(args: &mut Vec<String>) -> (EncoderPref, bool, bool)` extrahieren.

**Datei:** `crates/senmei-media/src/encoder/mod.rs`
